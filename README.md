Software engineer building clean full-stack products with **TypeScript** and **Python**. Exploring applied AI (agents, RAG).

## Featured projects

- **[PingPanda](https://github.com/remoale/pingpanda)** - Event-monitoring SaaS with auth, Stripe billing, and Discord alerts ([live](https://pingpanda-murex.vercel.app))
  - Next.js, TypeScript, PostgreSQL, Clerk, Stripe
- **[Realtime Chat](https://github.com/remoale/realtime_chat)** - Private chat rooms that self-destruct after 10 minutes ([live](https://realtime-chat-self-ten.vercel.app))
  - Next.js, TypeScript, Redis, realtime sync
- **[Amsterdam](https://github.com/remoale/amsterdam)** - Interactive Airbnb explorer for Amsterdam listings ([live](https://amsterdam.streamlit.app))
  - Python, Streamlit, Pandas, NumPy
- **[MetroSwap](https://github.com/remoale/MetroSwap)** - Campus marketplace for books and academic materials ([live](https://metroswap-73a05.web.app))
  - Full-stack product: auth, listings, chat, payments
- **[Academic Search Engine](https://github.com/remoale/academic-search-engine)** - Article search indexed with custom AVL trees and hash tables
  - Java, data structures
